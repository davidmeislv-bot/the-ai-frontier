Anthropic’s Claude Ship lets AI agents approve your code changes — if your team’s policy allows it

The new suite reviews pull requests, fixes failing checks, and can sign off on routine changes on its own. Anthropic suggests running the approval part in observe-only mode first.

By Wire Willow Staff · Nov 23, 2026 · 1 min read

The story in 30 seconds

  • The suite: Code Review is generally available; PR Steward and Claude Approvals are new and in beta. PR Steward is designed not to approve or merge anything itself.
  • The decision: Claude Approvals applies a plain-language policy file the team writes, and can approve routine changes on its own or send riskier ones to a person. Anthropic recommends observe-only mode first.
  • The offer: Eligible Enterprise organizations can claim at least $10,000 in Claude Ship credits, to use within 30 days of claiming, by January 15, 2027.
  • The limits: It is not available to organizations with Zero Data Retention, the HIPAA configuration, or customer-managed encryption keys.

Anthropic is moving Claude from writing code to deciding when that code is ready to ship. On Monday, the newly public AI company launched Claude Ship, a set of agents that review pull requests, fix the problems they find, and approve routine changes under rules each team writes itself.

The suite has three parts. Code Review, already generally available, reads proposed changes against the codebase and posts its findings to the pull request. PR Steward, new and in beta, handles what comes after: failing automated checks, merge conflicts, and feedback from the review. After every push it comments on what it changed and how to undo it. It is designed not to approve or merge anything itself. Claude Approvals, also new and in beta, is the one that holds the decision: it applies an approval policy the team writes as a file in the repository, in plain language, and can approve routine changes on its own or send riskier ones to a person. Anthropic recommends running it in observe-only mode first, to build confidence before letting its approval count toward merging.

Developers can try it on their own pull requests with a new /ship command in Claude Code: run it, and Claude pushes the change, opens the pull request, reviews it, and works through the feedback and failing checks. For teams, an administrator turns it on one repository at a time, choosing the review depth, when reviews run, and monthly spending limits. It works with existing branch protection and required checks.

Anthropic says its own Claude Code team, where Claude writes most of the code, merged more than twice as many pull requests from June to September while the share that had to be reverted fell by more than 40%. Those are the company’s own figures, not independently verified, and Anthropic’s own documentation notes that Claude Ship “uses AI and may miss bugs, security vulnerabilities, or other issues.”

Claude Ship is available on Claude Team and Enterprise plans for repositories on GitHub, and usage is billed on tokens. Eligible Enterprise organizations can claim at least $10,000 in Claude Ship credits, to use within 30 days of claiming, by January 15, 2027. It is not available to organizations with Zero Data Retention, the HIPAA configuration, or customer-managed encryption keys.
