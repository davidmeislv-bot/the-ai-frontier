AI agents working for hackers found a software flaw nobody knew existed — and turned it into arbitrary file writes on a university server in about 11 minutes. In a later session, they used the same flaw to take full control.

Amazon Threat Intelligence published the account on November 20, and Ars Technica reported it on Tuesday. The campaign ran for about 48 hours starting September 8, aimed at universities in East Asia outside mainland China. Amazon found the operation because the attackers had left their own control server — running Cairn, an open-source framework that coordinates AI agents for penetration testing — exposed on the internet without a login, so its prompts, settings and results were readable by anyone.

The operators gave the agents a list of internet addresses and a single goal: obtain shell access. The prompts were written in Simplified Chinese and the scripts were set to China Standard Time. Amazon attributes the campaign to a China-linked actor with moderate confidence.

For most of the campaign, the agents failed. One run spent about 16 hours and 148 attempts trying to break into a university Redis server without success. Another spent more than six hours trying more than 30,000 credential combinations against a university GPU server, built from a list of about 80 real usernames gathered from the university's public presence, including faculty directories and academic papers. Then the agents reached a server running MONAI Label, an open-source tool for annotating medical images. They mapped its interface, found an upload feature that took a filename, and tested whether the filename could be altered to write files outside the intended folder. It could. Amazon said the agents went from mapping the application to writing arbitrary files on the server in about 11 minutes.

In a later session, the agents planted a reverse shell in a file Python loads automatically at startup, then triggered a training API endpoint that spawned a new Python process, which imported the payload and established a reverse shell running as root — the account that controls everything on the machine. The human operator then pointed the agents at a second university running the same software.

Amazon assessed with high confidence that the flaw was a zero-day, because no fix, advisory or prior mention of it existed when the agents found it. The flaw, a path-traversal weakness in the software's upload endpoints, is now tracked as CVE-2026-133968, rated critical, and CISA added it to its exploited-vulnerabilities list on November 23. The maintainers merged a fix on October 19, published a security advisory on November 18, and shipped the patched version, 0.8.6, on November 22. Anyone running version 0.8.5 or older on a reachable network should treat the server as possibly compromised.

The episode is part of a wider pattern. Palo Alto Networks reported that attackers used Cairn in 25 autonomous operations against at least 19 organizations, and an earlier report from Gambit Security documented a Chinese operator using Cairn in at least 105 attacks, compromising at least 27 companies to varying degrees. Amazon's security chief, CJ Moses, wrote that the framework "is being adopted in both espionage and criminal operations."
