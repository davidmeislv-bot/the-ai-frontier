State-backed hacking groups from China and North Korea are using an AI-powered attack framework that can move from first scan to privileged access in minutes, Microsoft warned this week.

The tool is called ARTEX, an open-source framework for penetration testing that appeared on GitHub in July. It lets an operator set a target and a goal, then hands the work to AI agents that plan the attack, run the tools, track what they find and report back. Microsoft said in a report published on Wednesday that groups including Salt Typhoon and Crystal Typhoon, tied to China, and Onyx Sleet and Pearl Sleet, tied to North Korea, have folded it into their operations. Two other groups Microsoft tracks, Storm-0940 and Storm-3358, are using it as well.

Microsoft's warning is not that the attacks are new. The techniques — scanning for exposed systems, guessing passwords, exploiting known flaws, hunting for secrets left in public code — are familiar. The change is speed and scale: ARTEX automates the sequence, and Microsoft says it can go from reconnaissance to persistent, privileged access within minutes, depending on how it is set up and how well the target is defended. In one case Microsoft cites, an agent went from searching GitHub for client secrets to pulling data from an Azure Key Vault in five minutes.

The framework has spread fast. A Chinese cybersecurity company, ThreatBook, claimed ownership of ARTEX in November and is selling a paid version, and the research firm Infrawatch counts more than 130 variants in circulation, making it the most widely used framework of its kind.

The campaigns Microsoft describes are already reaching real targets. Storm-0940's attack on the IT provider ConnectWise led to attempted sign-ins at more than 2,250 Microsoft 365 tenants, and one password-spraying run logged more than 151,000 failed sign-ins, peaking at 2,900 a minute. Other ARTEX-linked campaigns touched banks in South Korea and India, the British domain registrar 123 Reg and the European Commission. The FBI and Amazon Web Services had already warned about the tool earlier in November. Wire Willow covered a similar case in November, when AI agents found and broke into a server in 11 minutes: Hackers' AI agents found a zero-day in 11 minutes.

"These campaigns illustrate how threat actors use ARTEX to automate various stages of the attack chain," Microsoft's threat intelligence team wrote.
